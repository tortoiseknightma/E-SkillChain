ALG-08 · 覆盖广度与 held-out 效果联合排序

本 campaign 已验证“多能力局部通过”不等于组合可接受：R17/R26 的 Multi + Recipe 有较高 body 增益却触发 hard-error 门，R29 的 Multi + Style 保持 hard-error delta=0 但总体仅 +1.6667pp；只有 R12 的单项 Style 达到正式接受门。

已验证机制

剩余问题
优先诊断 Multi/Recipe 的 hard-error 增量和多分支 fan-in interaction；不要把 rejected Bank 拼成新 parent，也不要用排名覆盖 acceptance gate。
若另启周期的预测
至少两个 capability 分支通过局部 screen，且组合 body75 macro ≥ +2pp；每项能力 floor ≥ −5pp、CI95 low ≥ 0、hard-error delta ≤ +1pp。
